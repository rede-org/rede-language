# Rede.Language

Rede.Language is intended to provide the syntax and semantic enforcement for the Rede programming language. It will handle tokenization and lexical analysis, parse Rede source code, and validate its syntax and semantics.

The project is in its initial setup; these language components have not yet been implemented.

## Build

Install the .NET 10 SDK, then run:

```sh
dotnet build Rede.Language.slnx
```
